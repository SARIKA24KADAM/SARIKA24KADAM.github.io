# Sarika Kadam — Portfolio

Personal portfolio site: [sarika24kadam.github.io](https://sarika24kadam.github.io/).

## Files

- `index.html` contains the profile, experience, education, volunteering, project cards, and contact links.
- `assets/sarika-kadam.jpg` is the profile photo shown near the top of the page.

## Edit profile details on GitHub

1. Open this repository and select `index.html`.
2. Select the pencil icon to edit the file.
3. Use the section navigation labels (About, Experience, Education, Volunteering, Projects, Contact) to find the text to change.
4. Keep the HTML tags around the text, such as `<p>...` and `<h3>...`.
5. Select **Commit changes** and commit to the `main` branch.
6. After GitHub Pages finishes updating, refresh the live site. A hard refresh (Ctrl+F5) can clear an older cached version.

## Edit using VS Code

1. Clone `https://github.com/SARIKA24KADAM/SARIKA24KADAM.github.io.git` or open that repository in VS Code.
2. Edit `index.html` and save.
3. To change the photo, replace `assets/sarika-kadam.jpg` with your new image using the same filename.
4. Commit and push the changes to `main`. GitHub Pages will deploy the update.

Only add projects to this public portfolio when their repositories are public or when you intend to share their names and descriptions publicly.
